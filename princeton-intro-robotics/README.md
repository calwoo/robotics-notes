# Princeton Introduction to Robotics

Study notes following Princeton University's public [ROB 345/549: Introduction to Robotics](https://irom-lab.princeton.edu/intro-to-robotics/) course taught by Anirudha Majumdar.

The course develops a robotics stack around three interacting areas:

1. planning and control;
2. state estimation, localization, and mapping; and
3. robot learning.

The public course uses the Crazyflie quadrotor for project-based work and culminates in vision-based navigation through imitation learning.
